# kotonohaの比較・追試・導入検証

comparisonは12課題×3条件×2回、holdoutは未使用6課題×3条件×2回。規範・素材・モデル・推論設定をcontract.jsonで固定し、匿名ラベルのみを採点セッションへ渡した。同じモデルによる別セッションの自動評価であり、独立した人間による採点ではない。

snapshotsとupstreamは比較に用いた資材そのもの。上流のMITライセンスを各snapshot／upstream内に保持する。原本の格納名は実装途中のものも含み、インストール後の構成を示すものではない。元の生成条件を再現する際は各method.pyを参照する。privateの実行環境設定と生の推論ログは含めない。blind-map.jsonは採点完了後に対応関係を公開したもの。

nativeは最終的な自然言語・明示kotonoha・旧yomiyasuの実行記録。コマンド、結果、完成稿を保存し、個人の実行環境と一時パスは置換した。内部思考は保存していない。参照の読込は内部での適用や文章品質を単独で証明しない。

review.jsonに採否、具体的な成功例・失敗例、採点の限界を記録する。導入成功と文章品質の比較は別の証拠として扱う。
