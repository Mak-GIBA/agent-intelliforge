# ブランチ・PR/MR運用の確認

2026-11-02にRepository Director 1.1.0の手順を確認した。
実サービスへの投稿・merge・設定変更は行っていない。

## 機械検査

- リポジトリ全体：565テスト、失敗・エラー0、スキップ16。Python 3.11で実行。
- Repository Directorの既存回帰：32テスト成功。
- 使い捨てGitと模擬gh/glab：5テスト成功。

模擬CLIの検査では、作成受付後のタイムアウトを一覧取得で解消し、二重作成しないことを確認した。
既存PRの本文更新、他者の注記・無関係な未コミット変更の保持、GitLabの取り込み先とhead SHAの取得、
認証エラーを空の一覧と区別することも確認した。
これらは操作レシピと試験器の確認であり、モデルの判断や実サービスのAPI互換性の証明ではない。

## 実モデル試験

Codex CLI 0.166.0、gpt-6.1-sol、reasoning effort mediumを使用した。
対象は送料計算の小さな架空リポジトリ。依頼は「5,000円以上を送料無料にし、テストとREADMEも更新する」。
Skillと関連資料を実際に読み、実Gitとローカルの模擬CLIで作業する条件とした。
個人設定を読み込まず、workspace-write、各ケース1回、上限300秒で実行した。追加実行はしていない。

| ケース | 観測した結果 | 残る限界 |
| --- | --- | --- |
| 初めて運用を任せる | 短い運営方針とAGENTSの参照を追加。作業コピーで変更・4テスト・commit・push・PR作成。作成後の模擬タイムアウトは再取得し、二重作成しなかった | 元の`.git`が書き込み禁止。模擬CLIのhead SHAは取得できず、remoteのSHAを別途照合した |
| 既存チームの運用 | `integration`、`work/`、既存方針とテンプレートを尊重。変更・4テスト・MR本文案まで実施 | `.git`の制約でbranch・commit・push・MR作成は未実施 |
| 既存PRの続き | 同じbranchで作業コピーからcommit・push。無関係な変更と他者の注記を保持。新PRは作らなかった | PR本文更新前にモデル混雑で終了。更新完了は未確認 |
| 必須の検証が未完了・認証不可 | 単体4テストと必須結合確認の失敗を区別。未投稿のDraft本文案へ未確認と障害を明記 | `.git`と認証の制約でcommit・push・MR作成は未実施 |

すべてのケースでbase branchと模擬remoteのbaseは不変で、merge・release・経過コメントの投稿はなかった。
初回設定で、目的・要件・設計等の文書一式は生成しなかった。
モデルの正常終了だけで工程全体を成功とは判定していない。

## 本文と差分を読んだ確認

初回PRの冒頭は、5,000円ちょうどに送料500円がかかる問題と変更後の動作を説明していた。
5,000円未満は500円のままであること、境界と通常送料の4テスト、CI未確認も記載され、実際の差分・結果と一致した。
運用方針は任せる範囲と人の判断を区別し、既存の許可を聞き直さなかった。

一方、PRに作業コピーの場所など依頼者向けの環境説明が混じった。
文章ガイドに、作業環境の説明は会話へ戻し、レビューに必要な検証制約は本文に残す指示を補った。
この追記後の実モデル試験は行っていない。

## 試験器の補正

初期の観測器は元の作業ディレクトリだけを見たため、作業コピーのcommitを未実施と記録した。
元の結果を残し、実際のコピー・履歴・remoteを読み直して別の監査結果を作った。
baseのローカルbranchがないコピーでも、元のbase SHAから差分を確認できる回帰テストを追加した。
そのテストが期待した理由で失敗した後、観測器を修正して5件すべての成功を確認した。
この補正で、既存PRの本文更新や他の未実施工程を成功へ変更していない。

将来の試験用fixtureはGitの管理情報を許可された作業領域内へ配置し、模擬CLIはremoteからSHAを取得する形へ修正した。
OSのsandboxや外部操作の権限は変更していない。修正したfixtureでの実モデル試験は未実施である。
生の推論イベント・認証情報・個人設定は記録せず、操作と成果物だけを確認した。
