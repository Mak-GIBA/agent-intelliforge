# UX共通入口の確認

2026-11-02にUX Stack 1.5.0の共通入口`ux`を確認した。
既存のOOUI設計、可視化、ハーネスは直接呼び出す方法を保ち、入口が依頼に応じて組み合わせる。

## 機械検査

全体576テストは失敗・エラー0、スキップ16で終了した。
追加した4件では、標準導入・診断・解除、旧版からの入口追加、外部コマンドを使わない入口単独追加、同名のユーザー管理・手編集Skillの保護を確認した。
単独追加では、既存部品の所有情報と内容が変わらず、再実行で同じ入口を使えることも確認した。

初回の全体検査では、キット全体と既存ハーネスの版数が同じという前提で2件が失敗した。
入口だけの追加では実行部品を変えないため、検査対象をハーネス自身と対応する設計資材の版数へ修正し、関連検査と全体検査を再実行した。
キットと入口は1.5.0、既存ハーネスと設計資材の仕様は1.4.0のままである。実行ロジックや既存の専門Skillは変更していない。

## 実モデルによる判断の確認

Codex CLI 0.166.0、gpt-6.1-sol、reasoning effort medium、read-onlyで、架空の7依頼をまとめて1回、上限300秒で試した。
入口と専門Skillの実ファイルを読み、工程、変更できる範囲、保持するもの、完了条件を返す条件とした。
モデルは正常終了し、7件を返した。入力ファイルは不変だった。
操作記録はローカルの資料読込とファイル一覧の取得だけで、アプリやハーネスの起動、外部接続はなかった。

| 依頼 | 実際に返した手順と範囲 |
| --- | --- |
| 新規アプリの設計・実装 | OOUI整理、導線と画面の可視化、実装、ブラウザーと契約の照合へ進む |
| 設計のみ | 正常・失敗・入力保持を図と契約へまとめ、実装やサーバー・ハーネスを開始しない |
| 問題点の指摘のみ | 新しい画像と操作でauditし、原因を分析する。再設計成果物や修正を追加しない |
| 再設計を含むレビュー | auditの所見から構造を分析し、図で案を比較する。コードと承認済み契約を保持し、新案を承認済みにしない |
| 検索条件保持の改善 | 該当Journeyと必須テストを使ったfocused runで修正・再確認する。全体再設計や新規契約を要求しない |
| 局所的なCSS修正 | ボタン周辺だけを修正・表示確認する。全体監査や設計資料一式を追加しない |
| 人が編集した図の取り込み | 三者比較で依頼範囲を契約へ反映し、競合・未対応編集を保持する。実装には進まない |

単語の一致だけで判定せず、実際の工程と変更範囲を読んだ。
レビューでも再設計案を扱い、提案と採用反映を区別していた。指摘だけ・設計まで・CSSだけという依頼も区別していた。
参照したのは入口、3つの専門Skillと関連する設計・レビュー・契約資料だった。
7件を一括で扱った試験なので、依頼ごとのコンテキスト削減量を測ったものではない。

判断試験後、ハーネスのrunに含まれる修正・再確認を親側で二重実行せず、同じ実行IDの完了まで追う説明を補った。
この追記後にモデルは再実行していない。実アプリの実装・操作や、入口からハーネスを通すE2Eの試験でもない。
生の推論イベントや認証情報は保存せず、指示、操作、回答、入力のハッシュ、終了状態を確認した。

## このPCへの反映

既存の管理済みUX構成へ、所有権・ハッシュ検査とロックを使って入口だけを追加した。
既存5部品の所有情報と実内容、Codex設定、hooks、共通AGENTSが不変であることを前後で照合した。
管理manifestの更新前コピーを所有者限定の権限で残し、新入口と配布元の一致を確認した。
statusは1.5.0でready・core_ready・integrations_readyがすべてtrue、失敗項目なしだった。
このstatusではブラウザーやモデルを起動せず、任意の外部デザインMCPの接続確認も行っていない。

## 再現用の入口

```bash
python3 -B -m unittest discover -s tests -p test_install_codex_ux_stack.py -v
python3 -B tools/codex-ux-stack/evals/entrypoint.py
# 実モデル試験を明示的に行う場合だけ、新しい出力先を指定する
python3 -B tools/codex-ux-stack/evals/entrypoint.py --apply --out /absolute/path/to/new-output
```

通常の導入・診断・回帰テストからモデル試験は実行しない。
