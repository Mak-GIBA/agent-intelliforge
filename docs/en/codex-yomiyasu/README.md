# kotonoha: clear, natural Japanese writing

[日本語](../../codex-yomiyasu/README.md) · [Installation](installation.md) · [Usage](usage.md) · [Validation](../../codex-yomiyasu/validation.md)

4.0.0 consolidates clarity, paragraphs, explanatory depth, hedges and naturalness into one discoverable Skill. Use `$kotonoha` and describe the task, including structure-only, caveat-only or diagnosis-only requests.

Rules, helpers, upstream originals and licenses live inside kotonoha. Short requests need only the entry; long-form and file-review instructions load when relevant. The workflow does not search sibling Skills, load entire upstream manuals or repeatedly regenerate the draft.

Latest stable yomiyasu and meiseki releases are candidates until source differences and capabilities pass review. UPSTREAMS.json distinguishes integrated revisions from available releases; capabilities.json maps preserved behavior to rules and evaluation cases.

Owned, unedited legacy yomiyasu, paragraph-writing and japanese-direct-writing entries are backed up and retired during migration. Edits, extra files and unmanaged entries stop migration. Installer and kit aliases named yomiyasu remain compatible. External APIs, hooks, quizzes and PDF features are outside this writing integration.
