# kotonoha: clear, natural Japanese writing

[日本語](../../codex-yomiyasu/README.md) · [Installation](installation.md) · [Usage](usage.md) · [Validation](../../codex-yomiyasu/validation.md)

4.1.0 preserves the v3 writing flow and its detailed rules inside one discoverable Skill. Use `$kotonoha` and describe the task, including structure-only, caveat-only or diagnosis-only requests.

Rules, helpers, upstream originals and licenses live inside kotonoha. Ordinary revision reads its core references. Paragraph, explanation, caveat and file-review details load under the preserved conditions. The workflow does not search sibling Skills, load entire upstream manuals or repeatedly regenerate the draft.

Latest stable yomiyasu and meiseki releases are candidates until source differences and capabilities pass review. UPSTREAMS.json distinguishes integrated revisions from available releases; capabilities.json maps preserved behavior to rules and evaluation cases.

Owned, unedited legacy yomiyasu, paragraph-writing and japanese-direct-writing entries are backed up and retired during migration. Edits, extra files and unmanaged entries stop migration. Installer and kit aliases named yomiyasu remain compatible. External APIs, hooks, quizzes and PDF features are outside this writing integration.

Version 4.1.0 restores the v3 writing flow and detailed rules inside one Skill. Reader-boundary, clarity, naturalness and reader-review references remain part of ordinary revision. Conditional paragraph, explanation, caveat and file checks retain their v3 triggers. FLOW.json records preserved normative blocks and wiring-only changes; prior v4.0 evaluation is historical evidence, not validation of these instructions.
