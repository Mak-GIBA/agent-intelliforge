# リポジトリ文書と研究をつなぐ

新規の目的整理も、既存コードの仕様整理も、[Repository Director](repository-director/usage.md)から始めます。
READMEとAGENTSから文書索引へ進み、関連する要件・設計・検証の正本を確認します。
判断を左右する不確実性がある場合は[Design Research](design-research/usage.md)を使い、結果と採用理由を設計・検証へ戻します。
旧upstream-*の入口は廃止しました。既存の文書・証拠・承認履歴は保持して参照できます。
