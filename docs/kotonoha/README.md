# kotonoha：明晰で自然な日本語を書く

[English](../en/kotonoha/README.md) · [導入](installation.md) · [使い方](usage.md) · [検証](validation.md)

[工程と詳細資料](flow-preservation.md)に、各資料を読む条件をまとめています。

kotonoha 5.0.0は、日本語の執筆・推敲を一つのSkillで行います。通常は `$kotonoha` と依頼内容を指定します。段落だけの修正や診断も同じ入口で範囲を指定できます。

規則・検査器・原典・ライセンスはkotonohaフォルダに揃い、他の日本語Skillを探しません。基本の推敲では読者境界・明晰化・自然さ・読者レビューの資料を読みます。段落・説明・留保・ファイル検査は作業内容に応じて追加します。上流原本の全文を毎回読み込まず、同じ原稿を工程ごとに再生成しません。

上流はyomiyasuとmeisekiの最新安定版を検出し、差分の確認と能力比較を経て採用します。取得した最新版と、kotonohaへ統合・検証した採用版は別に表示します。実際の採用状態はSkill内のUPSTREAMS.json、能力と評価ケースの対応はcapabilities.jsonで確認できます。

3.0.0までのyomiyasu・paragraph-writing・japanese-direct-writing入口は、所有元を確認できる未編集版だけ更新時にバックアップして退役させます。編集・追加ファイルや管理外の同名Skillは自動で消しません。配布名・キットID・Plugin名はkotonohaへ統一し、旧名の実行入口は廃止しました。既存環境は[更新手順](installation.md)で移行します。

これは両上流を統合した独自Skillです。原版の自動フック・外部判定API・理解度クイズ・PDF機能は自動導入しません。能力比較の結果と制約は[検証結果](validation.md)を参照してください。

規則の具体例と例外は参照資料に保持しています。4.1.1では、Skillの見出しや説明から開発経緯の文言を整理しました。規範の対応と変更範囲は機械照合し、文章品質の確認範囲は[検証結果](validation.md)に版ごとに記録しています。
