# kotonoha — 明晰で自然な日本語を書く

読者が一度読んで内容を理解できる文章を作る。文章の声や立場を足さず、事実・否定・条件・確信度を守る。詳しさや短さ自体を目的にしない。

執筆と推敲は、同梱の `../yomiyasu/references/workflow.md` を読んで進める。meisekiの明晰化を先に適用し、段落・説明・留保を必要な範囲で整え、yomiyasuの自然さで仕上げる。一つの下書きを使い、工程ごとの全文再生成や他の日本語Skillの再帰的な呼び出しをしない。

通常は完成稿だけを出す。制作説明、自己評価、変更報告は依頼されたときだけ本文の外へ分ける。短文・メール・局所修正には不要な説明や章立てを足さない。既に十分な文章は残す。

これはmeisekiとyomiyasuの原版そのものではなく、出典を分離して管理する独自Skillである。上流原本の全量読込は不要。工程中に示す参照だけを読む。原本・版・ライセンスは隣接するyomiyasuの管理資料で確認できる。

検査は `intelliforge kit-run yomiyasu --agent claude --tool writing_lint.py -- <原稿> [--before <原稿>]`。Python・Node.jsは導入時に準備した専用環境を使う。
Claude Code対応は試験対応。実機未検証の機能を検証済みと扱わない。
