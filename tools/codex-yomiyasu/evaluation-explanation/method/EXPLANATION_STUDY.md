# 説明の深さの比較契約

2026-10-11、生成前に固定。既存の評価課題・出力は保持し、説明の深さに関する12課題を追加する。baselineは作業開始時の2.0.0-proposal.2、improvedは今回のproposal.3。上流は同じv1.1.1原本。新旧それぞれ2回、計48生成を独立したCodexセッションで実行する。モデル・推論設定・CLI版は実環境から取得してcontract.jsonへ固定する。温度はCLIで制御しない。

素材、読者、保護事項は explanation-tasks.json で先に固定する。新規解説には明示した仮想例を許可し、推敲には資料の展開だけを許す。十分な原稿、メール、根拠不足を対照とし、追加説明が不要な場合の退行も探す。

生成時は各版の執筆規則を展開する。両条件の上流と共通資料は同じ。improvedの説明参照だけは課題の事前フラグに従って展開する。この実験は規範の文章品質比較であり、モデルが必要な参照を自力で選ぶことの証明ではない。参照選択は別のネイティブ試行で確認する。既存のSkill・ユーザー設定・AGENTSはCLI単位で無効化し、実環境は変更しない。

生成順と匿名ラベルを固定seedで無作為化する。採点は別セッションで行い、素材・依頼・保護事項・完成稿のみを渡す。規範・条件・版・実行時間は渡さない。同じモデルによる独立自動評価であり、人間2名の独立評価ではない。結果の公開前に具体的な成功例と失敗例も親エージェントが読む。

評価する8軸は具体性、因果の明瞭さ、読者理解、自然さ、情報効率、段落構造、意味保持、指示者向け表現の不在。各0〜4（0:目的不達、1:大幅な修正、2:局所修正が必要、3:実用可能、4:ほぼ修正不要）。説明不要な課題では情報を足さず必要なことが分かる状態を高く評価する。意味改変と制作メタは別に箇所と理由を記録し、平均で相殺しない。

主指標は説明対象E01〜E05,E09〜E12の対応のある「具体性・因果・読者理解」の平均差。探索的な改善の目安を+0.25点とする（統計的有意差や一般的優越の基準ではない）。意味改変と制作メタが増えず、自然さ・情報効率の平均が0.25点以上低下しないことも必要。E06〜E08の安全性と不要な補足は個別に確認する。出力長、実行時間、実測入出力トークン数も記録し、短さを単独の勝敗にしない。

480秒を各生成・採点の上限とし、同時実行2。失敗は保持し、自動再試行しない。欠測は文章の低品質と区別し、全試行と完了試行の分母を併記する。生成と採点は重ねない。規範を変更したら元の結果を上書きせず、別契約・未使用課題で再評価する。改善を測れなかった場合はその事実を記し、規範の追加を再検討する。インストーラー自己テストはこの品質指標に含めない。
